<h1 align="center">REST API built with <a href="https://symfony.com/" target="_blank">Spring Boot </a> to create and manage reading guides for comic books.</h1>

<br>

I'm a comic book fan that is looking to dive deeper into various characters and stories. Reading guides can often get complicated. This REST API let's you easily create and manage reading guides.

There are CRUD-endpoints for creating comics, characters, writers & authors, reading guides and items for your reading guides.

This project is still in early development, with more features planned to be added.
  
## Planned features
* Searching and filtering
* Connecting to an external comic API to retrieve comic information for the reading guides instead of creating them manually
* Tracking reading progress
* Authentication
* Front-end with React (I might make a separate repository for this)
* Load Testing & Balancing
* Caching
* Horizontal scaling
* Database redundancy
